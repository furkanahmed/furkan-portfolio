## ⚡ Overview

A performance-first, modern developer portfolio crafted with **Next.js (App Router)** and **Tailwind CSS**. Designed with an authentic, human-centric tone, dark-mode engineering aesthetic, and refined micro-interactions.

### 🌟 Key Features
- **Interactive Cursor Spotlight & Grid Reveal:** Subtle emerald/sky ambient glow tracking cursor movements with dynamic dot-masking.
- **Scroll Reveal (Intersection Observer):** Butter-smooth viewport fade-in and slide-up animations without heavy animation libraries.
- **Genuine & Verified Data:** No artificial claims; all 6 featured projects, teaching experiences, and client platforms are physically verified.
- **Dynamic Project Details (`/projects/[id]`):** Dedicated pages highlighting real-world technical architecture, challenges faced, and live deployments.
- **Fully Responsive & Accessible:** Flawless rendering from mobile (320px) to ultra-wide displays (1920px).

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18.18.0 or later)
- npm or yarn

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/furkanahmed/furkan-portfolio.git

# 2. Enter project directory
cd furkan-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
